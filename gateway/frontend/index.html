Explorador de endpoints — GYM_MOSTER

Interfaz simple (sin frameworks) para los 104 endpoints reales del gateway: /api/admin/** (server-administrator) y /api/page/** (web-page). server-informations y server-register no tienen ruta en el gateway y no se llaman directamente.

Todo se llama a través del gateway (un solo puerto). El despliegue real es Kubernetes (sin docker-compose) — apuntá la URL de abajo a donde tengas el gateway corriendo (port-forward, minikube, etc.).
